## How to Update Prices & Discounts (Inventory Manager)

### First-time setup (once, ~2 minutes)
1. Get a free GitHub key: open
   https://github.com/settings/personal-access-tokens/new
   (while logged in as `Dragula003`), give it a name, pick an expiration,
   set **Repository access** → *Only select repositories* → `cozy-glow-website`,
   and under **Repository permissions** set **Contents → Read and write** (required),
   then **Generate token** and copy the `github_pat_…` string.
2. Open the manager: https://cozy-glow-website.vercel.app/admin/
   (on your machine locally: `python3 -m http.server 8000` in the project folder → http://localhost:8000/admin/)
3. Paste the key and click **Save key** — it is stored only in that browser.
4. Press **🔑 Test key** — it confirms the key can read *and* publish (no changes are made by the test).

> **“Resource not accessible by personal access token” error?** The key exists but its
> Contents permission is missing/read-only. Fix without re-creating anything:
> https://github.com/settings/personal-access-tokens → your token → **Edit** →
> **Contents → Read and write** → **Save**, then press **Save & Publish** again.

### Everyday use
1. Open `/admin/` (footer link **Owner → Inventory Manager**, or the ⚙ button on the site).
2. Edit a product:
   - **Original price** — the printed/retail price
   - **Discount %** — sale price is calculated for you (shown as *Customer pays*)
   - **Customer pays** — or type an exact price; the original is kept when you lower it
   - **Price on request** — checkbox; card shows *Price on Request* instead of a number
   - **Product name / Type** — also editable
3. Or use **Quick tools**: `Apply to all` (bulk festive discount) / `Clear all discounts`.
4. Click **Save & Publish** → the site rebuilds and the change is live in ~1 minute.

Discounts are always calculated from the original price, so applying one twice never lowers the price twice.
A published card shows: struck original price, sale price, and a green **25% OFF** badge.

### What happens on Save
- Only changed files are committed (`data/products/*.json` + `data/products.json`) — one Git commit.
- Vercel sees the commit and redeploys automatically (~1 minute).
- The key is sent only to `api.github.com` and never stored anywhere but the browser's localStorage.

## How to Add a New Product

1. Create a new file in `data/products/your-product.json`:
```json
{
  "name": "Product Name",
  "category": "candle",
  "tag": "",
  "price": 599,
  "scent": "Note 1 · Note 2 · Note 3",
  "desc": "Product description",
  "burn": "40–45 hours",
  "size": "200g · 8oz jar",
  "color": "#F3E8DC",
  "link": "https://www.instagram.com/thecozyglowcandles/",
  "image": "/images/product-name.svg"
}
```

2. Run `bash build.sh` to regenerate `products.json`
3. Commit and push
