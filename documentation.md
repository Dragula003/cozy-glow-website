## How to Update Content

### Option 1: Admin Panel (Recommended)
1. Go to `/admin/` on the live site
2. Log in with your email (magic link)
3. Click **Products** → add/edit/delete
4. Upload images directly
5. Click **Publish** → site updates automatically

### Option 2: GitHub
1. Go to https://github.com/Dragula003/cozy-glow-website
2. Edit files in `data/products/` or `images/`
3. Commit changes → Netlify auto-deploys

---

## How to Add a New Product

1. Create a new file in `data/products/your-product.json`:
```json
{
  "name": "Product Name",
  "category": "candle",
  "tag": "",
  "price": 599,
  "scent": "Note 1 · Note 2 · Note 3",
  "desc": "Product description",
  "burn": "40–45 hours",
  "size": "200g · 8oz jar",
  "color": "#F3E8DC",
  "link": "https://www.instagram.com/thecozyglowcandles/",
  "image": "/images/product-name.svg"
}
```

2. Run `bash build.sh` to regenerate `products.json`
3. Commit and push

## How to Replace a Product Photo

1. Add the photo to the `images/` folder (e.g., `urli-star.jpg`) — 1000px max side, ~80% JPEG quality
2. Update the product JSON in `data/products/`: change `"image"` to the new path
3. Run `bash build.sh` to regenerate `data/products.json`
4. Commit and push
