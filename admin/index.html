One-time setup: paste your publish key

The key lets this page save changes to your website. It is stored only in this browser and sent only to GitHub — nowhere else.

Get your free key from GitHub (about 2 minutes):
  1. Open github.com/settings/personal-access-tokens/new while logged in as Dragula003
  2. Token name: anything (e.g. Cozy Glow Manager) · Expiration: your choice
  3. Repository access: pick Only select repositories → cozy-glow-website
  4. Repository permissions: find Contents → set it to Read and write ⭐ (this is the important one — without it, publishing fails)
  5. Click Generate token, copy the github_pat_… string (shown only once), paste it above and press Save key
Already got the “Resource not accessible” error? Your key just needs one permission switched on:
open github.com/settings/personal-access-tokens → click your token → Edit → Contents → Read and write → Save. Then press Save & Publish again — no need to paste the key again.

Keep it secret — anyone with this key can change your website files.
